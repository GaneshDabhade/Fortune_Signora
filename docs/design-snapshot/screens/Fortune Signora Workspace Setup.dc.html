Workspace setup

Administration is where enterprise software either earns trust or loses it, and the difference is almost always honesty about consequence. Four things here are irreversible or externally visible — the data region, the URL, domain verification, and deletion — so each one states what it breaks, who it affects and how long the old behaviour survives, before the button is pressed rather than in a toast afterwards.
