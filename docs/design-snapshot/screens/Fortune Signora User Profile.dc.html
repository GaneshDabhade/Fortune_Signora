Profile & preferences

The first personal surface in the platform, and the one place where administration inverts: settings here belong to the person, not the workspace. That creates the module's central problem — half these fields are owned by the identity provider, a quarter are capped by workspace policy, and only the rest are genuinely theirs. Every field says which it is, rather than accepting an edit that a directory sync will silently overwrite tonight.
