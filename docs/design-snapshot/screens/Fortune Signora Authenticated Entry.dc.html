02 · Customer journey — the resolution ladder

Six gates, in fixed order, first match wins

Authentication hands over an identity and an intent — the route the person was trying to reach. Everything after that is a single ordered walk. The order is not arbitrary: each gate depends on the one before it resolving, and a gate that fails produces a designed screen rather than a redirect loop. Engineering implements this as one component with one ordered rule list; no module performs its own entry redirect.

04 · Home is a slot, not a screen

One route, four compositions

Every authenticated person lands on /w/:workspace/home. What renders there is resolved from their role, and the resolution is a composition of cards from a shared catalogue — not a separate screen with its own layout, navigation or breadcrumb.

The Executive Dashboard already built is the executive composition of Home. It does not sit beneath Home in a hierarchy; it is what Home resolves to for a CRO. That is why the breadcrumb "Home → Executive Dashboard" reads oddly — it describes a parent that is the same page.

Why this scales and a second screen does not
A new module ships a card contract, and the four compositions decide whether to include it. With a separate Home, every new module forces a negotiation about which of two screens it appears on, and the answer is usually "both", which is how a product acquires two half-maintained landing pages.

08 · Entry loading, empty & error
Entry loading — shell first

The shell paints as soon as the workspace resolves, before any card has data. Rail, header and page frame are real; only the cards shimmer. Nothing about entry is allowed to show a full-screen spinner, because a blank screen after a successful login is indistinguishable from a failed one.

Northwind Global
Budget: shell painted under 400ms from resolution, briefing streamed, cards independently. A slow card never delays the others — Home is composed, so it degrades card by card.
Empty — the quiet day

Distinct from an empty workspace. Everything is connected, and today there is genuinely nothing urgent. This is a success state and must read as one — an empty worklist that looks like a broken page teaches people to distrust a full one.
