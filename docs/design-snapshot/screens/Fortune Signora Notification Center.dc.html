Notification Center

Notification settings fail in one predictable way: the product sends too much, the person mutes everything, and then misses the one message that mattered. This module is built against that failure. Every control shows the volume it will actually produce, the page opens by naming what you are ignoring, and mutes expire by default — because a mute set in March is how a deal is lost in September.

A digest is not a list of everything that happened. It is the difference since the last one, ordered by what changed most — which is why a quiet week produces a short digest rather than the same template with smaller numbers.

Mutes expire by default

Every mute is created with an end date — 7 days, 30 days, or until a stated event. Permanent is available and requires typing the word, because a mute set in March is how a renewal is missed in September. Seven days before expiry, Signora tells you it is about to resume.
