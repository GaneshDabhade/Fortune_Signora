Sixteen excellent screens that do not yet add up to one product

Each module is individually strong: the thinking is rigorous, the density is right, the AI is accountable, and the writing carries argument rather than filler. Measured against each other, though, they are sixteen dialects of the same language. Nobody consumes the App Shell. Every screen re-declares the palette by hand. The type scale has thirty-six sizes where the system specifies nine, and forty-four per cent of corner radii are off-scale. None of this is visible in a screenshot; all of it is visible in a demo where you move between modules.

The good news is the shape of the problem. There is no disagreement about what the product should look like — the drift is accumulated convenience, not competing opinions. That means the refactor is mostly mechanical, and can be done without redesigning a single module.
